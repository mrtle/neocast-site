# neocast.us

Company site for **Neocast**, the pro-human broadcast: home of *10 Humans vs. AI* (reality TV) and *VPRWRE* (news).
Static, single page, served by GitHub Pages from the repository root (custom domain in `CNAME`).

- `index.html`, `404.html`, `assets/site.css`: edit directly.
- `assets/img/`: black-and-white photos (set photos from @mwtle/@10humansvsai, founder photo from LinkedIn) and the share image `og.png`.
- `assets/fonts/montserrat.woff2`: Montserrat (SIL Open Font License), matching the NEOCAST wordmark.
- "The Take" list shows three built-in stories and swaps in the newest three from `https://vprwre.com/posts.json` in the browser when it can.
